# Class Notes Checker

A style guide and an automated checker for alumni Class Notes submissions to the *Peddie Chronicle*.

1. **Style guide** — the master proofreading document: spelling (names and places), punctuation, state abbreviations, and AP-style formatting (dates, numbers, titles, class-year apostrophes), with right/wrong examples.
2. **Checker** — paste in a batch of Class Notes and get each likely error highlighted, with the rule it breaks and a suggested fix. The editor makes the final call.
